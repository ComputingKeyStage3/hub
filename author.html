Turn a worksheet into a lesson

Paste your worksheet on the left using the simple marks below, press Convert, then Preview to try it exactly as a student would. When it's right, copy the JSON into lessons/your-lesson-id.json and add the lesson to lessons/index.json.

The marks you can use

# Title — the lesson title (first line).
> One sentence — the description shown on the home page.

## A heading — starts a reading page. Plain lines under it become paragraphs, and lines starting with - become bullet points.

[write] Explain what a variable is — a written answer box. Add (30 words) at the end to set how much you'd like.

[code] Fixing the greeting — a Python IDE task. Put the starter code in a fenced block straight after, between lines of ```. Options on the same line: +turtle (adds the drawing canvas), +inputs: Ada, 12 (answers for input()), +expect: Hello (what the output should contain).

[quiz] Which one is a loop? then option lines: * correct and - wrong. Add ? a hint under the options to give a hint.

[mc] …, [blanks] The [[cat]] sat, [order] a | b | c, [short] … +keywords: loop, repeat — assessment questions.

[screenshot] Show your program running — a screenshot upload.
[video] https://… — an embedded video.
[link] https://… | Trinket — a link out.

Add +lock: HAWK to any task line to keep it shut until you give the class a code.
